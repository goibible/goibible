PHASE 1: SCHEMA MIGRATION
=====================================================

STEP 1.1: Create migration backup
  Command: sqlite3 atomic_bible.sqlite3 .backup /backup/original.db

STEP 1.2: Add BCP47 columns to verses table
  ALTER TABLE verses ADD COLUMN language TEXT NOT NULL;
  ALTER TABLE verses ADD COLUMN script TEXT;
  ALTER TABLE verses ADD COLUMN region_variant TEXT;

STEP 1.3: Modify primary key
  Change from: (version, book, chapter, verse)
  To: (language, conical, chapter, verse)

STEP 1.4: Create necessary indexes
  CREATE INDEX idx_language ON verses(language);
  CREATE INDEX idx_canonical ON verses(conical, chapter, verse);

QUERY EXAMPLES AFTER MIGRATION
=====================================================

1. Get all verses in English:
   SELECT * FROM verses WHERE language = 'eng' ORDER BY conical, chapter, verse;

2. Get Hebrew verses (WLC):
   SELECT * FROM verses WHERE language IN ('heb', 'grk');

3. Get Chinese verses (CUV):
   SELECT * FROM verses WHERE language = 'chi' ORDER BY conical;

4. Count verses by language:
   SELECT language, COUNT(*) as verses 
   FROM verses 
   GROUP BY language ORDER BY verses DESC;

5. Join with books and filter by language:
   SELECT 
     v.chapter, v.verse, 
     b.long_name, 
     v.language,
     v.region_variant
   FROM verses v
   JOIN books b ON v.conical = b.conical
   WHERE v.language IN ('eng', 'chi')
   ORDER BY v.conical, v.chapter, v.verse;
