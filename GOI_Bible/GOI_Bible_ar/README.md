# GOI Arabic Translation

**Status: scaffolded; no translation has begun.**

`Reference_Bible/Arabic_Bible_VanDyck1865/` contains the public-domain Arabic
Van Dyck comparison reference, preserved source archive, reproducible
GOI-coordinate normalization, and the two documented versification merges.

When translation begins, this directory will contain only canonical UTF-8
`NNN_BOOK_CCC_VVV_GOI_Ar.txt` flatfiles translated from the Hebrew WLC and
Greek TR1550 source-language scaffolds. The Van Dyck text must not be copied
into GOI output.
