# GOI Russian Translation

**Status: scaffolded; no translation has begun.**

`Reference_Bible/Russian_Bible_RUSSYN1876/` contains the public-domain
Russian Synodal comparison reference, preserved source archive, and a
reproducible spine-address alignment. Unlike Arabic, Russian's versification
does not drop in cleanly: 784 GOI addresses are absent and 851 Russian
addresses are extra (90%+ of both in Psalms). A formal Russian->GOI
versification map is required before this reference can anchor translation
QA; see `Reference_Bible/Russian_Bible_RUSSYN1876/alignment_report.json`.

When translation begins, this directory will contain only canonical UTF-8
`NNN_BOOK_CCC_VVV_GOI_Ru.txt` flatfiles translated from the Hebrew WLC and
Greek TR1550 source-language scaffolds. The Synodal text must not be copied
into GOI output.
