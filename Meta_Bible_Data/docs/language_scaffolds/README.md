# Per-language scaffold records

One committed Markdown record belongs here for every language started in GOI:
`<bcp47-language-subtag>.md`. Create it from
`../language_scaffold_intake_template.md` before downloading a reference Bible
or generating the first verse file.

These records are append-only audit summaries. They point to the preserved
reference source, its provenance/hash manifest, GOI coordinate exceptions,
Strong's-rendering scaffold, reports, and release commits. They must not be
replaced with an empty placeholder or removed during cleanup. See
`../language_scaffold_playbook.md` for the required layout and gates.
